# State

Miejsce na opis aktualnego stanu, mechanizmów, zależności.

Każdy plik powinien opisywać domenę, albo subdomenę.

np.
- `world.md` - opisuje świat, geografię itp.
- `world-generation.md` - opisuje subdomenę - generowanie świata

Pliki ogólne:
- `PROGRESS.md` - handoff między sesjami (sekcja „Teraz” = aktualny stan)
- `progress-log.md` - archiwum starszych sekcji PROGRESS
- `FEATURES.json`, `PERF.md` - statusy wymagań, wyniki wydajności
